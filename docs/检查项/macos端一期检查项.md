# macOS 端一期检查项

> 建议准备：有权限账号、无权限账号、空目录、包含图片/PDF/文本/不支持类型的目录，以及一个较大文件。

## 一、登录与会话

- [ ] 正确账号密码登录成功
- [ ] 登录后进入文件列表
- [ ] 错误账号或密码有明确提示
- [ ] 网络断开时登录失败提示正常
- [ ] 服务异常时可以重试
- [ ] 重新打开 App 后有效会话可恢复
- [ ] STS 凭证过期后能自动刷新或重新登录
- [ ] 会话失效时不会静默失败

## 二、文件浏览

- [ ] 根目录加载正常
- [ ] 文件夹进入、返回上级正常
- [ ] 文件名称、类型、大小、更新时间显示正确
- [ ] 空目录有明确提示
- [ ] 手动刷新后内容更新
- [ ] 列表加载失败可以重试
- [ ] 列表模式与缩略图模式切换正常
- [ ] 图片显示缩略图
- [ ] 非图片显示默认图标
- [ ] 长文件名、中文名、特殊字符显示正常
- [ ] 大量文件滚动无明显卡顿

## 三、文件与文件夹管理

- [ ] 有权限时可新建文件夹
- [ ] 文件夹名称为空或非法时禁止创建
- [ ] 同名文件夹有明确提示
- [ ] 可重命名文件
- [ ] 可重命名文件夹
- [ ] 重命名后列表立即更新
- [ ] 可删除文件
- [ ] 可删除文件夹
- [ ] 删除前必须二次确认
- [ ] 取消删除后文件仍存在
- [ ] 删除成功后列表刷新
- [ ] 无权限时相关入口隐藏、禁用或给出提示

## 四、上传

- [ ] 通过文件选择器上传单个文件
- [ ] 通过文件选择器上传多个文件
- [ ] 拖拽单个文件上传
- [ ] 拖拽多个文件上传
- [ ] 拖拽到正确目录后上传到该目录
- [ ] 拖入不支持内容时有提示
- [ ] 上传进度显示正常
- [ ] 上传成功后目标目录出现文件
- [ ] 上传失败显示原因
- [ ] 上传失败可以重试
- [ ] 上传任务可以取消
- [ ] 网络中断后任务状态正确
- [ ] 大文件上传正常
- [ ] 同名文件处理符合预期

## 五、下载

- [ ] 下载文件成功
- [ ] 可选择保存位置
- [ ] 下载进度显示正常
- [ ] 下载完成后本地文件可打开
- [ ] 下载失败有明确提示
- [ ] 下载失败可以重试
- [ ] 下载任务可以取消
- [ ] 文件夹不能直接作为单文件下载
- [ ] 无下载权限时提示明确

## 六、文件预览

- [ ] 图片预览正常
- [ ] PDF 预览正常
- [ ] 文本文件预览正常
- [ ] 预览失败有错误提示
- [ ] 不支持的文件类型提示仅可下载
- [ ] 预览页可返回文件列表
- [ ] 预览页可继续下载

## 七、传输中心

- [ ] 上传任务可查看
- [ ] 下载任务可查看
- [ ] 显示任务名称、方向、进度和状态
- [ ] 成功、失败、进行中状态准确
- [ ] 失败任务可以重试
- [ ] 进行中任务可以取消
- [ ] 无任务时显示空状态
- [ ] 任务完成后状态及时更新

## 八、macOS 体验

- [ ] 窗口缩放后布局不重叠
- [ ] 宽屏双栏或多栏布局正常
- [ ] 最小窗口尺寸下主要功能仍可操作
- [ ] 文件操作入口清晰可见
- [ ] 拖拽上传区域反馈明显
- [ ] 菜单、按钮、弹窗样式一致
- [ ] 浅色模式显示正常
- [ ] 深色模式显示正常
- [ ] App 前后台切换后状态正常
- [ ] 退出并重新打开后数据和会话状态符合预期
- [ ] 无明显卡死、闪退、空白页或静默失败
