Private Domain Drive · UI Prototype

基于 PRD 的一期 HTML 原型

面向 5 人以内小范围共享场景，覆盖登录成败、目录/文件 CRUD、列表/缩略图浏览、上传下载、预览、权限、传输任务，以及 Android 系统分享导入。 Android 以窄屏触控、底部导航、列表 + FAB 为主；macOS 以 Cupertino 宽屏双栏/三栏和拖拽上传为主。

产品定位轻量私人共享文件 App，不是完整商业网盘
目标平台Android 390×844 · macOS 1280×820 固定画布
一期能力登录成败、目录/文件 CRUD、列表/缩略图、上传下载、预览、权限、系统分享
明确不做公开分享、回收站、在线编辑、复杂搜索
Scope

一期范围提醒

原型只表达信息架构、核心流程和权限差异，不模拟真实 OSS / STS 请求。

Android 统一浅/深色主题与移动端交互，不复用桌面 hover 模式
不做对外公开链接、评论标签、版本历史、后台成员管理
