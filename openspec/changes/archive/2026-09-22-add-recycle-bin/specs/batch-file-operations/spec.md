## MODIFIED Requirements

### Requirement: 用户可以批量删除已选项目
系统 SHALL 在当前身份具备删除能力且存在选中项目时提供批量删除操作。系统 MUST 在执行前展示受影响对象数量和“移入回收站、30 天内可恢复”说明，并支持文件与文件夹；选中的文件夹 SHALL 连同其全部子对象移入回收站。

#### Scenario: 确认批量删除
- **WHEN** 用户确认删除包含文件和文件夹的选择
- **THEN** 系统将选中对象及选中目录下的对象移入回收站，并刷新受影响的文件列表和目录缓存

#### Scenario: 用户取消批量删除
- **WHEN** 用户在回收站确认弹窗中选择取消
- **THEN** 系统不得向 OSS 发出复制或删除请求，且保留原有选择

#### Scenario: 批量删除部分失败
- **WHEN** 批量删除中有部分对象无法移入回收站
- **THEN** 系统显示成功与失败数量、保留失败对象的重试信息，并仅从本地视图移除已成功移入回收站的对象
