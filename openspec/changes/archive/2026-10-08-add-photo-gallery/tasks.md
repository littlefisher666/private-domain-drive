## 2. 照片索引（photo-index）

- [x] 2.1 定义索引条目数据模型（对象 key、媒体类型、拍摄时间、大小、所在目录、视频缩略图映射、索引版本号）
- [x] 2.2 实现 EXIF 拍摄时间解析（DateTimeOriginal 优先、文件修改时间兜底），视频取媒体元数据时间
- [x] 2.3 实现全量扫描建索引：递归 ListObjects 全部前缀、过滤媒体类型、写本地副本并生成 OSS 清单对象 `.gallery/index/photos.json`（内部对象收敛在 `.gallery/` 点前缀目录下，避免与用户自建目录撞名）
- [x] 2.4 实现清单对象读-改-写：ETag 乐观并发、冲突退避重试、超限标记待修复；JSON 损坏视为待修复
- [x] 2.5 实现待修复状态处理：进入相册页提示 + 后台全量扫描重建
- [x] 2.6 上传管线接入：媒体文件上传成功后触发索引增量更新（非媒体文件不触发）
- [x] 2.7 视频上传前截帧并上传 `.gallery/thumbs/<key>.jpg`，索引记录映射；截帧失败不阻塞上传、标记无缩略图
- [x] 2.8 删除联动清理：照片/视频删除成功后（相册页与文件页入口统一）增量移除清单条目与本地索引副本，存在缩略图映射的条目同步删除 `.gallery/thumbs/` 缩略图对象（失败不阻塞、容忍残留），本地原图缓存记录与文件一并删除
- [x] 2.9 超大图片缩略图本地生成：超过 OSS 图片处理大小限制（20MB）的图片上传时并行本地缩放（macOS NSImage / Android BitmapFactory 桥）并上传 `.gallery/thumbs/<key>.jpg`，索引记录映射；失败不阻塞上传
- [x] 2.10 存量缩略图后台补齐：进入相册页每次会话一次，为无映射的视频请求 OSS 截帧、为无映射的超大图片下载原图本地缩放，上传后增量写回索引，单个失败跳过
- [x] 2.12 点前缀条目统一隐藏：文件浏览与文件夹统计隐藏所有以点开头的文件/文件夹（`.trash/`、`.gallery/`、`.DS_Store` 等），替代各自的内部前缀单独过滤；目录级删除/回收操作不受影响

## 3. 相册时间线页（photo-gallery）

- [x] 3.1 `home_shell.dart` 双端导航加入口：Android 底部 Tab 4→5（文件/相册/传输/回收站/我的），macOS 侧边栏"文件"附近加"相册"；路由 `/gallery`
- [x] 3.2 时间线列表：按拍摄时间（EXIF 拍摄日期）倒序、双端按天分组，组头日期与数量，跨目录聚合，无照片的日期不显示
- [x] 3.3 缩略图网格加载：存在索引缩略图映射的条目（视频/超大图片）优先走缩略图对象，其余图片走 OSS 图片处理参数、无映射显示占位图，复用现有缩略图鉴权与磁盘缓存机制

- [x] 3.5 首次进入建索引进度占位：无本地索引时显示扫描进度，完成后加载时间线
