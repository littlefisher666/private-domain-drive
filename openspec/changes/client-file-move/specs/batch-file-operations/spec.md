## MODIFIED Requirements

### Requirement: 用户可以批量下载已选文件

系统 SHALL 在当前身份具备下载能力且至少选中一个项目时提供批量下载操作。批量选择状态下的业务动作 SHALL 仅包含下载、移动和删除，其中下载动作仅在当前身份具备下载能力时显示，移动动作仅在当前身份具备写入与删除能力时显示。系统 MUST 让用户一次选择目标目录，并为每个已选文件创建独立下载任务；系统 MUST NOT 将文件合并为 ZIP 或其他压缩包。

#### Scenario: 批量状态仅显示允许的业务动作
- **WHEN** 用户已选择至少一个项目
- **THEN** 系统在批量工具区只展示当前身份有权使用的下载、移动和删除业务动作，不展示分享、复制或重命名动作

#### Scenario: 多个文件下载到同一目录
- **WHEN** 用户选中多个文件并确认目标目录
- **THEN** 系统为每个文件创建独立下载任务，并将完成文件保存到该目录

#### Scenario: 选择中包含文件夹
- **WHEN** 用户发起的批量下载选择中包含文件夹
- **THEN** 系统递归展开文件夹中的文件，为每个文件创建独立下载任务，并在目标目录保留其相对目录结构

#### Scenario: 文件与父文件夹同时被选择
- **WHEN** 用户同时选择某个文件夹及其中的文件
- **THEN** 系统 MUST 对重复的对象路径只创建一个下载任务

#### Scenario: 目标目录存在同名文件
- **WHEN** 下载目标目录已存在与待下载文件同名的文件
- **THEN** 系统 MUST 自动使用不冲突的新文件名保存下载内容，且不得覆盖已有文件

#### Scenario: 批量移动已选条目
- **WHEN** 具备写入与删除能力的用户在批量选择状态发起移动并确认目标目录
- **THEN** 系统对全部选中条目执行移动流程，冲突与执行语义遵循移动能力（file-move）的规格
