# 工作区系统后退导航规范

## ADDED Requirements

### Requirement: 子目录后退返回上级目录

客户端在 Android 端的工作区目录浏览页 SHALL 拦截系统后退键（含手势）：当当前目录不是根目录时，后退 MUST 将当前目录切换为上一级目录，且不得退出应用或关闭页面。

#### Scenario: 子目录按后退返回上级

- **WHEN** 用户位于任意非根目录并触发系统后退
- **THEN** 当前目录切换为上一级目录，标题与文件列表同步更新，应用保持前台运行

#### Scenario: 深层目录逐级返回

- **WHEN** 用户在多层嵌套目录中连续触发系统后退
- **THEN** 客户端按目录层级逐级向上返回，直到根目录

#### Scenario: 退回过程中不丢失页面状态

- **WHEN** 后退返回上级目录触发重新加载
- **THEN** 目录列表在加载完成后正常展示，返回过程不出现白屏、退出或路由弹栈

### Requirement: 根目录后退退出应用

当当前目录为根目录时，客户端 SHALL 恢复 Android 系统默认的后退行为，即退出应用。

#### Scenario: 根目录按后退退出

- **WHEN** 用户位于根目录（全部文件）并触发系统后退
- **THEN** 应用按系统默认行为退出到桌面

#### Scenario: 后退状态随目录切换实时更新

- **WHEN** 用户通过任意入口（点击文件夹、返回上级按钮、侧边栏目录）切换当前目录
- **THEN** 系统后退键的拦截状态实时跟随当前目录更新，不出现状态滞后导致的误退出或无法退出

### Requirement: 桌面端不受影响

该后退导航拦截 SHALL 仅作用于目录浏览页的系统后退路由，不得影响其他页面（如预览页）的路由后退行为和 macOS 桌面端交互。

#### Scenario: 预览页后退行为不变

- **WHEN** 用户从目录浏览页进入文件预览页并触发系统后退
- **THEN** 预览页按路由栈正常关闭，返回进入前的目录浏览页
