# 提案：新增相册功能（add-photo-gallery）

## Why

当前客户端只能按文件夹层级浏览照片，用户想回看"所有照片"时必须在多个文件夹间跳转。私域网盘的核心使用场景之一是照片存储与回看，需要提供类似手机相册的体验：全量照片按拍摄日期时间线展示、列表用缩略图、点开才下载原图，本地空间可控。

服务端（阿里云 FC）零改动：缩略图由 OSS 图片处理实时生成，照片索引以 OSS 对象形式维护，全部能力由客户端 + OSS 约定实现，符合一期轻量架构。

## What Changes

- 双端新增"相册"入口：Android 底部 TabBar 由 4 个变 5 个（文件/相册/传输/回收站/我的），macOS 侧边栏"文件"下方新增"相册"项，共用同一套页面代码
- 照片索引：在 OSS 维护索引清单文件（如 `index/photos.json`），记录照片对象 key、拍摄时间（EXIF 优先、无 EXIF 回退文件时间）、大小、所在目录、视频缩略图映射等；首次使用全量扫描建索引（展示进度），之后随上传增量更新，冲突时可全量扫描修复
- 缩略图机制：列表永远显示缩略图——图片走 OSS 图片处理 URL 参数（`x-oss-process=image/resize,w_N`），视频缩略图在上传时由客户端截帧并存为独立 OSS 小对象（`thumbs/` 前缀）；超过 OSS 图片处理大小限制（约 20MB）的图片由客户端本地缩放生成缩略图同样存入 `thumbs/`，存量条目进入相册页时后台补齐
- 相册时间线页：按拍摄日期（天）倒序分组展示，双端一致，网格布局，双击/单击进入大图查看（复用现有预览与缩略图加载、鉴权、缓存机制）
- 云朵角标：角标 = 原图未缓存本机，无角标 = 已缓存；下载原图完成后角标即时消失；macOS 底部状态栏显示照片总数与未缓存数
- 大图查看：原图已缓存秒开；未缓存先放大显示缩略图并后台下载原图，完成后无缝替换。macOS 查看器：原图铺满预览区、信息栏在原图右侧（基础/来源/位置分组），顶栏与底部操作栏悬浮显示、鼠标静止 2 秒自动隐藏（含指针）；Android 沿用详情页交互（四方向滑动切换、推移动画、沉浸式布局，范围收敛为当前日期分组）并提供系统分享
- 视频条目不在线播放：双端点击视频展示截帧缩略图并提供下载原图，下载后写缓存记录但不自动播放
- 多选与剪贴板（macOS）：列表页支持拖拽框选与勾选（单击=打开大图、拖拽=框选、⌘+单击=加选/减选），支持全选（⌘A），选中后出现操作栏（全选/复制/下载原图/删除/取消）；⌘C 复制所选原图到剪贴板（按钮上不标注快捷键），⌘V 在相册页粘贴图片直接上传（隐式支持，无 UI 提示）
- 删除联动清理：照片/视频被删除（含回收站彻底删除，入口不限于相册页）后，客户端增量移除对应索引条目，并清理 OSS 上的视频缩略图对象与本地原图缓存记录
- 原图缓存自动清理：App 内执行（启动时 + 下载前检查），双策略——按时间（N 天未查看）与按容量（上限 5 GB，LRU 最久未查看优先）；不引入系统定时任务
- 平台差异：macOS 不做分享功能；Android 保留系统分享

UI 效果图已确认归档：`docs/ui/相册-安卓端.html`、`docs/ui/相册-macOS端.html`。

## Capabilities

### New Capabilities

- `photo-index`: 照片索引的构建与维护——全量扫描建索引、增量更新、冲突修复，以及视频缩略图截帧上传的索引数据约定
- `photo-gallery`: 相册时间线浏览体验——导航入口、按日期分组网格、缩略图与云朵角标、macOS 多选/框选/剪贴板操作、Android 系统分享
- `photo-viewer`: 大图查看与按需下载原图——缓存命中秒开、未缓存降级与后台下载、macOS 查看器布局与悬浮栏自动隐藏
- `original-cache`: 原图缓存管理与自动清理——缓存状态记录、按时间与按容量的双策略清理

### Modified Capabilities

（无——现有目录内浏览、缩略图加载、传输、回收站等规格行为均不变，相册为纯新增能力，机制上复用 `oss-image-thumbnails` 已定义的加载/鉴权/缓存机制）

## Impact

- **客户端子仓库**（`private-domain-drive-client/`）：主要改动集中于此
  - `lib/features/`：新增 gallery 模块（时间线页、大图查看器、选择状态、剪贴板桥接）
  - `lib/features/workspace/presentation/home_shell.dart`：Android 底部导航与 macOS 侧边栏各加一项
  - `lib/app/router/`：新增相册路由
  - 上传管线：图片/视频上传完成后触发索引增量更新，视频上传前截帧生成缩略图对象
  - 新增本地元数据存储（SQLite 或本地文件）记录照片索引本地副本、原图缓存状态与访问时间
  - 新增依赖：EXIF 解析、视频截帧、图片缓存（复用现有）
- **服务端子仓库**：零改动
- **OSS 约定**：新增 `index/photos.json` 清单对象与 `thumbs/` 缩略图对象前缀（客户端私有约定，无服务端接口变更）
- **文档**：`docs/Flutter架构设计.md`（新增 gallery 模块）、`docs/PRD.md`（相册能力）
